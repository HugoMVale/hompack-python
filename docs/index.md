# hompack

`hompack` provides python bindings for [hompack-fortran].

[hompack-fortran]: https://github.com/HugoMVale/hompack

## Installation

`odrpack` requires Python >= 3.12. Besides that, it only requires `numpy`.

In order to install the latest stable version from PyPI do:

```bash
pip install hompack
```

Alternatively, the very latest code (no guarantee it will work!) may be installed directly from
the source code repository:

```bash
pip install git+https://github.com/HugoMVale/hompack-python.git
```
